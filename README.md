# Peoples Portfolio

Cyberpunk portfolio site (React 19, Vite 7, tRPC, Tailwind 4, Three.js). Imported from `peoples-portfolio.zip`.

## Prerequisites

- [Node.js](https://nodejs.org/) 20+
- [pnpm](https://pnpm.io/) 10.x

## Setup

```bash
cp .env.example .env
pnpm install
```

## Develop

```bash
pnpm dev
```

## Build

```bash
pnpm build
pnpm start
```
